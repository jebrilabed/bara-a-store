## ⚡ الإعداد والتشغيل السريع

1. ثبت بيئة Node.js (الإصدار 18 أو 20+) ثم شغّل الأمر:
   ```bash
   npm install
   ```
2. انسخ ملف `.env.example` إلى `.env` وضعي إعدادات الاتصال بقاعدة بيانات PostgreSQL ومفتاح `AUTH_SECRET` الفريد للمتجر.
3. لقاعدة البيانات الجديدة:
   ```bash
   npm run db:validate
   npm run db:migrate:deploy
   ```
4. شغّل خادم التطوير:
   ```bash
   npm run dev
   ```
   ثم افتح الرابط: `http://localhost:3000/ar`

## 🛡️ سياسات النظام وإدارة المتجر

- **الواجهة:** عربية أصيلة مع دعم كامل للاتجاه من اليمين لليسار (RTL) وتصميم متجاوب لجميع الشاشات.
- **تخصيص المنتجات:** وحدة البيع الواحدة مرتبطة برمز SKU فريد ومخزون مستقل. الاختلافات في الحجم أو العطر تسجل كمنتجات مستقلة.
- **عائلات المنتجات المعتمدة:**
  - `SKINCARE`: العناية بالبشرة
  - `PERSONAL_CARE`: العناية الشخصية
  - `HOME_CLEANING`: المنظفات المنزلية
  - `HOME_FRAGRANCE`: العطور المنزلية
  - `AIR_FRESHENER`: معطرات الجو والمنسوجات
- **البيانات التفصيلية:** تدعم المنتجات حقولاً تفصيلية اختيارية: المكونات، ملاءمة البشرة، درجة الرائحة، طريقة الاستخدام، تحذيرات السلامة، تعليمات التخزين، سعة العبوة، المميزات، والشركة المصنعة.
- **سلة التسوق المحمية:**
  - سلة الزائر مؤمنة بكوكيز `HttpOnly` عشوائية وتخزين الـ Hash في قاعدة البيانات.
  - دمج تلقائي للسلة فور تسجيل دخول العميل.
  - تخزين لقطة سعرية لضمان عدم حدوث أي تلاعب بالأسعار من المتصفح.
- **إتمام الطلبات (Checkout):**
  - فحص الأسعار وخصم المخزون الحصري ضمن معاملة ذرية متزامنة (Interactive Transaction).
  - منع تكرار الطلبات باستخدام `idempotencyKey`.
  - خيارات الدفع: الدفع عند الاستلام (COD) والتحويل البنكي مع إيصال الدفع.

## 👤 حساب المدير الأول (Admin Bootstrap)

لا توجد حسابات أو كلمات مرور تجريبية افتراضية للمدير في قاعدة البيانات. يتم إنشاء حساب المدير الأول عبر السكربت المخصص مرة واحدة:

```bash
ADMIN_BOOTSTRAP_EMAIL="admin@baraastore.com" ADMIN_BOOTSTRAP_PASSWORD="YourStrongPassword123" npm run admin:bootstrap
```

## 🧪 أوامر التحقق والاختبار

- `npm run test:backend` — تشغيل اختبارات سياسات الباك إند والمنطق التجاري.
- `npm run typecheck` — فحص سلامة أنواع TypeScript.
- `npm run db:validate` — التحقق من صحة مخطط Prisma.
- `npm run db:generate` — توليد عميل Prisma Client.
- `npm run build` — بناء نسخة الإنتاج المحسّنة.

للمزيد من التفاصيل الفنية، راجع [تقرير تنفيذ الباك إند](BACKEND_IMPLEMENTATION.md) و[ملف README الرئيسي](../README.md).
