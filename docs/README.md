# متجر براعة

## الإعداد المحلي

1. ثبتي Node.js المتوافق مع Next.js 14 ثم شغّلي `npm ci`.
2. انسخي `.env.example` إلى `.env` وضعي رابطين لقاعدة PostgreSQL مستقلة خاصة بهذا المتجر، مع `AUTH_SECRET` فريد. لا تستخدمي بيانات اتصال أو أسرار متجر آخر.
3. لقاعدة جديدة وفارغة فقط، شغّلي `npm run db:validate` ثم `npm run db:migrate:deploy`.
4. شغّلي `npm run dev` وافتحي `http://localhost:3000/ar`.

لا تشغّلي `db:migrate:deploy` قبل فحص قاعدة بيانات موجودة. المستودع لم يكن يحتوي تاريخ Prisma migrations؛ أُضيفت لقطة أولية للمخطط السابق ثم ترحيل إضافي. إذا كانت قاعدة البيانات الحالية تطابق اللقطة، راجعي الجداول والعلاقات والقيود والبيانات أولاً، ثم سجّلي لقطة البداية كمنفذة باستخدام `prisma migrate resolve --applied 20261015000000_initial_schema --schema prisma/schema.prisma` قبل نشر الترحيل الإضافي. ظهر أثناء تشغيل الواجهة خطأ مؤكد بأن العمود `Product.type` غير موجود في قاعدة البيانات المضبوطة؛ لم تُطبق أي ترحيلات. لم ينجح فحص حالة الترحيلات بسبب منع تشغيل Prisma schema engine، لذا لا تزال ملكية قاعدة البيانات وبيئتها ومخططها الكامل غير مؤكدة. لا تطبّقي الترحيل عليها حتى تأكيد أنها قاعدة مستقلة تخص هذا المتجر ومراجعة خطتها.

## إدارة المتجر

- واجهة المتجر تبقى عربية وRTL، مع الاحتفاظ بالتنسيق الحالي.
- المنتج القابل للبيع له مخزون ورمز SKU واحد. عبوات أو روائح أو تركيبات مختلفة تُسجّل كمنتجات مستقلة؛ لا توجد خيارات ملابس أو ألوان أو مقاسات.
- أنواع المنتجات تشمل العناية بالبشرة، العناية الشخصية، العطور المنزلية، معطرات الهواء، والمنظفات المنزلية. أُبقي نوع المنظفات لأن المشروع الحالي يحتوي تصنيفاً ومنتجات تنظيف.
- تفاصيل المنتج الاختيارية تشمل المكونات وملاءمة البشرة والرائحة وطريقة الاستخدام والتحذيرات والتخزين والحجم والشركة المصنّعة.
- السلة محفوظة في قاعدة البيانات. سلة الضيف تستخدم رمزاً عشوائياً في cookie من نوع HttpOnly، ويُخزّن hash الرمز فقط.
- الخادم يعيد حساب إجمالي الطلب من الأسعار الحالية، ويخصم المخزون بشرط توافر الكمية، ويحفظ اسم المنتج والصورة وSKU والسعر في سجل الطلب.
- الدفع عند الاستلام فقط. لا توجد حالياً رسوم توصيل أو ضرائب أو بوابة دفع أو خصومات أو إرجاع/استبدال.
- تعرض الواجهة السعر بالشيكل كما كانت. تغيير العملة والبلدان والضرائب يحتاج قراراً تجارياً قبل الإطلاق.

## حساب المدير

لا يوجد مدير تجريبي أو كلمة مرور افتراضية. بعد تجهيز قاعدة المتجر وتطبيق migrations، أنشئي أول مدير مرة واحدة عبر `npm run admin:bootstrap` مع تمرير `ADMIN_BOOTSTRAP_EMAIL` و`ADMIN_BOOTSTRAP_PASSWORD` إلى العملية فقط. كلمة المرور يجب أن تكون فريدة وطولها 12 حرفاً على الأقل. لا تحفظي هذين المتغيرين في `.env` أو ملفات متتبعة.

## بيانات تجريبية

`npm run db:seed` يرفض العمل في الإنتاج، ويتطلب `SEED_DEMO_DATA=true`. يستخدم بيانات منتجات تجريبية فقط ولا ينشئ حساب مدير. شغّليه على قاعدة تطوير مؤقتة بعد التأكد من رابطها؛ لا تشغّليه على قاعدة العملاء.

## أوامر التحقق

- `npm run test:backend`
- `npm run typecheck`
- `npm run db:validate`
- `npm run db:generate`
- `npm run build`
